# 电量与费用定义

id为计量号、order为订单号、station为站点，均为字符串。kind取order或station。计量start/end必须带时区，区间[start,end)，最大72小时可调至168小时。energy以kWh或MWh输入，输出kWh。未知哨兵不等于零。
费率版本以本地+08日期[from,to)生效；日内时段必须完整无重叠覆盖0–24小时。默认11月17日调整尖峰价，可在API参数tariffs中提供相同结构版本清单。
计量段内假定匀速用电，电量按时长交集分配，最后一段修正Decimal除法尾数保证电量严格守恒。跨日以当地日期重选版本。
每站唯一总表电量减订单电量为损耗，按订单kWh占比分配。总表缺失、重复、负损耗或无订单承接损耗时标记异常，不强行分配。
订单应收=各分时电量×费率+损耗份额×loss_rate。先算站总额再最大余额分币，稳定id打破余数并列。JSON金额为Decimal字符串。账单bill为CNY，差额=应收-bill，容差边界包含。
版本最高者采信，同版冲突全部隔离；重复和旧版计入隔离。输入行数=采信+隔离。批次哈希包含输入摘要、规则版本、参数；复核乐观锁防止旧提交覆盖。

站点总表区间必须覆盖其全部订单区间；未覆盖标记总表未覆盖订单区间，损耗不强制分摊，账单结论为待复核。

## 月度最大需量

需量回传字段 meter、station、start、end、kwh；start/end 必须带时区且区间恰为半小时，区间须落在结算月份（本地 +08）。站内需量表必须唯一，否则该站待复核且不出账。同站同半小时重复或冲突全部隔离。

每站每月需量 = 全月半小时电量 ÷ 0.5 小时的最大值（kW，保留三位）。每站唯一需量费 = 需量 × demand_rate（CNY/kW）。形成峰值的半小时内，各订单按与峰值区间重叠的电量占比分摊这笔唯一费用，分币按最大余额法分配并以订单号、读数号打破并列；责任合计恰等于站点需量费，不按各时段峰重复收费。

缺失半小时按同刻历史补数：取缺失日前最近 7 个同刻回传值均值，记录采用的日期与数量；不足则退到全月同刻均值、站点可用均值。补数取历史均值，不会超过已有实测峰值，故峰值仍来自真实回传；若补数槽成为最大值，页面标注峰值来源为“补数”供核对。缺失超过全月 10% 或整月无回传判为补数失败/无回传，该站不出新账，若有历史账则保留上一版可读结算。

账单台账按 (月份, 站点, 版本) 保存：同站同月仅一笔“当前”账单；内容指纹相同的重试复用原账单不新增；未复核前输入变化就地升版；已复核后输入变化保留原记录为“已替代”，另生成新的当前版本。复核用整数版本乐观锁，陈旧提交返回 409。
